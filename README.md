# VisionAI Studio

AI-assisted photo editing studio for social media posts and stories.

## Features
- BLIP image description
- Suggested filters based on image description
- 13 local filters: Vintage, Cinematic, Retro, Black & White, Dreamy Glow, Soft Blur, Warm Sunset, Cool Blue, Bright & Clean, Matte, Sharp, Pink Aesthetic, Original
- Filter strength slider
- Text-prompt-to-filter recipe matching
- Instagram/Facebook-style export layouts
- Optional text overlay on images
- Caption, hashtag, and caption-option generator
- Download edited images as PNG

## Important limitations
This starter project uses a local vision model to describe images and Pillow to apply effects. Prompt-based editing maps phrases to existing filter recipes; it does not yet generate new pixels using a diffusion model, replace backgrounds with generated scenes, publish directly to social media, or track live trends. Captions are style-based templates, not generated by a large language model.

## Setup (Windows + VS Code)

1. Install Python 3.13 if it is not already installed.
2. Open this folder in VS Code.
3. Open Terminal > New Terminal.
4. Create a virtual environment:

   ```powershell
   py -3.13 -m venv .venv
   ```

5. Activate it:

   ```powershell
   .\.venv\Scripts\Activate.ps1
   ```

6. Install dependencies:

   ```powershell
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   ```

7. Run the app:

   ```powershell
   python app.py
   ```

8. Open the local URL printed in the terminal, normally `http://127.0.0.1:7860`.

The first run downloads the BLIP model, so it needs an internet connection and can take several minutes. Keep the terminal open while using the app.

## If PowerShell blocks activation
Run:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
```

## Suggested demo
Upload a photo, analyze it, review filter suggestions, enter a prompt such as "warm vintage film", apply a filter, add text, select a story layout, download the edited image, and generate a caption and hashtags.
